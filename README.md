# AA-Crew-Absence-Prediction-Reserve-Optimization
End-to-end ML system predicting AA crew sick-calls and optimizing reserve staffing. XGBoost AUC 0.87, Recall 0.91 on 820,876 real BTS flights. Original Schedule Stress Score ranked #4 of 35 features by SHAP. Reserve optimization estimated $1.3M annual benefit.
